# Documentation Guide

This folder contains the design, content, architecture, animation, component, and execution specifications for the portfolio project.

## Files

### `VISION.md`

Defines why the website exists, who it serves, what it should feel like, and what it must not become.

Read this before making creative direction changes.

### `DESIGN.md`

Defines visual rules including typography, spacing, grid, color, components, responsive behavior, and anti-patterns.

Read this before building or modifying visual components.

### `ANIMATION.md`

Defines motion principles, GSAP usage, choreography, durations, easing, ScrollTrigger rules, responsive motion, reduced motion, and performance expectations.

Read this before adding animation.

### `CONTENT.md`

Defines the content model, copywriting direction, project structure, SEO content requirements, and factuality rules.

Read this before adding or rewriting portfolio content.

### `ARCHITECTURE.md`

Defines the technical architecture, directory structure, rendering strategy, component islands, image handling, SEO architecture, and testing strategy.

Read this before making framework or structural changes.

### `COMPONENTS.md`

Defines the component inventory and the responsibilities of shared UI and interaction primitives.

Read this before creating a new component.
